# ETHGlobal Mumbai

Written so a judge can see what this repository is, what it is not, and what the rules ask for. Deadline: **Saturday 7 November 2026, 09:00 IST**.

## Track

Submit on the classic **From Scratch** track, for **ENS — Best Use of ENSv2** (Sepolia is allowed).

Do not also enter **Best Integration of ENSv2 into an Existing Project**. That prize is Continuity-only and requires Ethereum mainnet. OnShift was built in this repository during the event, and it runs on Sepolia.

ENS qualification, from the prize page:

- ENSv2 is the product, not a name dropped into an unrelated app. Passes are ENSv2 names. The gate reads `getState`, the live `ops` subregistry, and the per-pass Permissioned Resolver. Public Check also reads the same records through UniversalResolverV2.
- The demo is functional. Overview, activity, float, orders and Public Check are contract reads. Issuing, paying, refunds, check-ins, revoke, Playground `tryIt`, and break-glass are transactions. The UI does not ship a fixture list of passes. Anyone with a wallet can issue a Playground pass on the live site.
- The code is MIT, in this repository.

## What was written for OnShift

- `contracts/src/PassIssuer.sol`, `PassResolverLib.sol`, `ShiftGate.sol`, `IncidentSwitch.sol`, `Playground.sol`, `OnShiftTypes.sol`, `ShopFactory.sol`, `EpochResolver.sol`
- Demo sandbox: `demo.<org>` UserRegistry, `SandboxGate`, Playground that only mints `Demo cashier` / `Demo agent` under `*.demo.onshift.eth`
- Till alias (`till.<org>` → `quarantine.<org>` via ENSv2 `setAlias`), watchtower-only quarantine, auditor-attested promote
- `sdk/gate.mjs` and `scripts/counterparty.mjs` — a second agent that refuses names that are not live or whose till is quarantined
- `contracts/src/ensv2-local/` — a test double with the same ABI and role bits, so `npm test` can run without a fork. The product does not use it. Sepolia uses the ENSv2 contracts pinned in `contracts/script/SepoliaENSv2.sol`.
- `contracts/test/OnShift.t.sol`, `AuditFindings.t.sol`, and `SepoliaFork.t.sol`
- `app/` — landing page, Playground, customer pay, console, staff app, and public check (with DEMO PASS banner)
- Deploy, upgrade-to-sandbox, register, and smoke scripts
